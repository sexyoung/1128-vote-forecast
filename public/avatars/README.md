# 候選人照片

`CardCover` 會自動找這個資料夾。放進來就會顯示，沒有的檔案就退回原本的文字方塊，
不需要改任何程式。

## 檔名

```
[選區代號]-[政黨英文簡稱]-[候選人英文拼音].[副檔名]
```

三個欄位都要小寫以外照原樣，拼音用連字號接（`chen-mei-ling`）。

**政黨英文簡稱**用 `src/shared/candidates.ts` 裡的 `PartyId`：

| 代號    | 政黨               |
| ------- | ------------------ |
| `DPP`   | 民主進步黨         |
| `KMT`   | 中國國民黨         |
| `TPP`   | 台灣民眾黨         |
| `NPP`   | 時代力量           |
| `TSP`   | 台灣基進           |
| `PFP`   | 親民黨             |
| `TSU`   | 台灣團結聯盟       |
| `NP`    | 新黨               |
| `GPT`   | 台灣綠黨           |
| `SDP`   | 社會民主黨         |
| `CMG`   | 中華民族致公黨     |
| `LABOR` | 勞動黨             |
| `NPSU`  | 無黨團結聯盟       |
| `OBA`   | 小民參政歐巴桑聯盟 |
| `TWP`   | 台灣工黨           |
| `JRP`   | 司法改革黨         |
| `ZSM`   | 正神名黨           |
| `MJP`   | 麻將黨             |
| `IND`   | 無黨籍／其他       |

**選區代號**是 `Contest['id']`，依選舉種類有三種長相：

| 選舉         | 樣子                           | 來源                               |
| ------------ | ------------------------------ | ---------------------------------- |
| 縣市長       | `TPE-EXECUTIVE-1`              | `getContests()`                    |
| 議員         | `NTP-COUNCIL-2`                | `council-districts.ts`，中選會公告 |
| 鄉鎮市長     | `town-10002040-TOWNSHIP`       | 圖資，`map-shapes.ts`              |
| 鄉鎮市民代表 | `town-10002040-REPRESENTATIVE` | 同上                               |
| 村里長       | `vill-10002040001-VILLAGE`     | 同上                               |

例子：

```
TPE-EXECUTIVE-1-DPP-chen-mei-ling.jpg
NTP-COUNCIL-2-KMT-lin-chih-hao.jpg
town-10002040-TOWNSHIP-NPP-huang-ta-wei.webp
```

## 規格

- 正方形，短邊至少 208px（封面在 2x 螢幕上是 104px）
- `.jpg`、`.webp`、`.png` 都吃，`avatars.ts` 的 `avatarExtensions` 列了支援的副檔名
- 單張建議 60KB 以內

## 什麼時候才會有資料

中選會的期程（中選務字第 1153150253 號，115/8/20，全文在 `docs/`）：

- 2026-08-31 ～ 09-04 受理候選人登記
- 2026-10-23 抽籤決定號次
- **2026-11-12 公告直轄市長候選人名單**
- **2026-11-17 公告直轄市議員、縣（市）長、縣（市）議員候選人名單**
- 2026-11-28 投票

在 11 月中之前沒有官方名單，`getMockCandidates()` 產生的是假的中文姓名，沒有英文
拼音，檔名仍湊不出來。

鄉鎮市民代表與村里長那一層由各縣市選舉委員會公告，不在中選會那份裡，要另外查。

## 授權

政黨官網與候選人競選辦公室的照片是有著作權的。放進這個資料夾等於隨網站一起散布，
逐張確認授權後再放；來源與授權狀態記在 `sources.csv`。
